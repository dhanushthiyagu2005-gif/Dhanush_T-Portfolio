# Dhanush T – Portfolio (React + Vite + Framer Motion)

    npm install
    npm run dev      # local dev server
    npm run build    # production build in dist/

- Content (projects, live links, skills, services): `src/data.js`
- Approved client reviews: add to `APPROVED` in `src/data.js` (empty by default – no fake reviews)
- Styles: `src/index.css`  · Profile photo: `src/assets/images/profile.jpg`
- Replace the illustrated project covers with real screenshots: add images to `src/assets/projects/`
  and swap `<Art/>` in `src/components/Projects.jsx` for an `<img loading="lazy">`.
- WhatsApp number: `WA` in `src/data.js`.
